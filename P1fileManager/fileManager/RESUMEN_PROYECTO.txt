1️⃣  LEE LA DOCUMENTACIÓN
    → Abre GUIA_INICIO.md para ver el plan de implementación
    → Revisa EJEMPLOS.cpp para ver código de referencia

2️⃣  PRUEBA EL PROGRAMA ORIGINAL
    → Compila y ejecuta ./fileManager para entender cómo funciona
    → Prueba comandos: ls, lls, upload, download

3️⃣  IMPLEMENTA EL SERVIDOR (server.cpp)
    → Iniciar servidor en un puerto
    → Esperar conexiones
    → Crear thread para cada cliente

4️⃣  IMPLEMENTA LA LÓGICA DEL SERVIDOR (clientManager.cpp)
    → Recibir peticiones del cliente
    → Ejecutar operaciones en FileManager local
    → Enviar respuestas

5️⃣  IMPLEMENTA EL CLIENTE (client.cpp)
    → Conectar al servidor
    → Replicar interfaz de main_fm.cpp
    → Enviar peticiones en lugar de ejecutar localmente

6️⃣  PRUEBA LA COMUNICACIÓN
    → Terminal 1: ./server
    → Terminal 2: ./client
    → Verifica que funcione igual que ./fileManager

║                      COMPILACIÓN Y EJECUCIÓN                           ║
╚════════════════════════════════════════════════════════════════════════╝

En Linux/WSL:
    cd cmake-build-debug-aws-ubuntu
    make
    ./server      # Terminal 1
    ./client      # Terminal 2
    ./fileManager # Terminal 3 (referencia)

En Windows con MinGW/MSYS:
    mkdir build
    cd build
    cmake .. -G "MinGW Makefiles"
    mingw32-make
    server.exe    # Terminal 1
    client.exe    # Terminal 2
